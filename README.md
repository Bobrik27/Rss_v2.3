# Run Swift Studio — сайт студии и WB Audit v2.3

> Многоязычная витрина услуг AI-автоматизации с блогом, новостями и интерфейсом анализа товаров Wildberries.

## Зачем создавался проект

Сайт должен объяснять, чем занимается Run Swift Studio, показывать направления работы и приводить посетителя к заявке. Отдельный инструмент **WB Audit** задумывался как наглядный пример AI-услуги: пользователь вводит ссылку на товар и получает результаты анализа.

**RSS в имени репозитория — Run Swift Studio, а не агрегатор RSS-лент.**

## Что есть в коде

- Лендинг с разделами услуг, компетенций, подхода, команды и контактов.
- Русская, английская и немецкая версии главной страницы.
- Блог и новости на Markdown через Astro Content Collections.
- React-виджет **WB Audit** со вводом товара, отображением хода анализа и результата.
- Запросы к внешним n8n webhooks для получения данных, запуска анализа и проверки статуса.
- Компоненты общей навигации, оформления и темизации.

## Как связан сайт с AI-ядром

Посетитель → сайт Astro/React → n8n webhooks → внешнее Python/AI-ядро → статус и результаты анализа.

В этом репозитории находится **интерфейс**, а не полный backend. Для работы WB Audit нужны отдельно настроенные n8n и AI-сервис.

`_core_remote` — символическая ссылка на локальный диск разработчика, а не включённая копия ядра. Описание backend в архитектурных документах не означает, что его исходники находятся здесь.

## Стек и локальный запуск

**Astro 5, React 19, TypeScript, Tailwind CSS 4, Lucide, Markdown, n8n-интеграции.**

```sh
npm install
npm run dev
```

Для сборки: `npm run build`. Для просмотра сборки: `npm run preview`.

## Состояние

Наиболее развитая из трёх отдельных версий сайта в этой подборке. WB Audit требует внешних сервисов; экран выбора тарифа в данной версии не является подтверждённой платёжной интеграцией. Локализация и контент местами незавершены.

README описывает найденные компоненты, а не подтверждает работу production-сервисов. При оформлении обзора сервисы не запускались.
